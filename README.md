# Movie Recommender System

A content-based movie recommendation app built with Python, scikit-learn, and Streamlit. It compares movie descriptions, genres, keywords, cast, and directors to recommend similar films.

## Project structure

```text
Movie-Recommender/
├── app.py
├── recommender.py
├── build_model.py
├── requirements.txt
├── README.md
├── .gitignore
├── .streamlit/
│   └── secrets.toml.example
├── data/
│   ├── tmdb_5000_movies.csv
│   └── tmdb_5000_credits.csv
└── model/
    ├── movie_list.pkl       # generated by build_model.py
    └── similarity.pkl       # generated by build_model.py
```

## 1. Install Python dependencies

Open a terminal in this project folder. Create and activate a virtual environment if desired.

Windows:
```powershell
py -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
```

macOS/Linux:
```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## 2. Add the datasets

Download the TMDB 5000 Movie Dataset from Kaggle (search for **TMDB 5000 Movie Dataset**). Place these two CSV files in `data/`:

- `tmdb_5000_movies.csv`
- `tmdb_5000_credits.csv`

The CSV files are not included in this starter project.

## 3. Generate the model files

Run:
```bash
python build_model.py
```

This creates `model/movie_list.pkl` and `model/similarity.pkl`. The two files are generated together so their row order stays aligned.

## 4. (Optional) Enable movie posters

Create `.streamlit/secrets.toml` based on `.streamlit/secrets.toml.example` and add your own TMDB API key:

```toml
TMDB_API_KEY = "YOUR_REAL_KEY"
```

You can also set the `TMDB_API_KEY` environment variable. The app still runs without a key, but posters will be unavailable. Never publish your API key in source code or commit `secrets.toml`.

## 5. Run the app

```bash
streamlit run app.py
```

## Troubleshooting

- **Missing model file:** run `python build_model.py` after adding the CSV files.
- **Missing CSV:** check the exact filenames and that they are inside `data/`.
- **Movie list/similarity mismatch:** regenerate both model files by running `python build_model.py`.
- **No posters:** check your TMDB key and internet connection; recommendations should still work without posters.
- **Module not found:** activate the virtual environment and run `python -m pip install -r requirements.txt`.

Only load pickle files you generated yourself or otherwise trust.
